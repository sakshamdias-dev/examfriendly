How To Use This Simulator

This interactive tool simulates how data moves across computer networks using different switching strategies.

1
Choose a Switching Technique: Select Circuit, Message, Packet, or MAC Table from the top bar or pick a Quick Preset.
2
Interact with the Topology Canvas: Drag any switch or computer node with your mouse/touch to re-arrange the layout. Hover over any node to inspect its internal memory buffer and routing tables!
3
Test Interception / Tapping: Enable "Tapping / Interception Demo" to see how intermediate nodes in Message Switching can inspect confidential payloads mid-transit!
